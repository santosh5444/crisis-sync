# CrisisSync: Multi-Facility Crisis Response Platform

A powerful, industry-agnostic crisis management solution designed for **Hospitals** and **Hotels**. CrisisSync provides real-time SOS tracking, staff coordination, and guest/patient services in high-pressure environments.

## 🚀 Key Features
- **Multi-Facility Architecture:** Dynamic UI toggles between Hospital and Hotel modes with industry-specific service lists and staff roles.
- **Real-Time SOS Dashboard:** Secure command center for admins to track, verify, and resolve emergencies instantly.
- **Staff Dispatch:** Smart assignment of tasks based on floor assignment and profession.
- **Lost & Found AI:** Cross-facility matching for lost items using smart metadata and real-time feeds.
- **QR Entry System:** Frictionless onboarding for guests and staff via facility-specific QR codes and fast-track links.
- **Secure Auth:** Multi-tenant administrative control via Firebase Authentication.

## 🛠️ Technology Stack
- **Frontend:** React (Vite), Tailwind CSS, Framer Motion
- **Backend:** Firebase Realtime Database
- **Authentication:** Firebase Auth
- **Icons:** Lucide-React
- **Charts:** Recharts

## 📦 Getting Started
1. Clone the repository
2. Install dependencies: `npm install`
3. Configure Firebase in `src/firebase/config.js`
4. Start the dev server: `npm run dev`
